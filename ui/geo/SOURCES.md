# Map geometry

Derived from Natural Earth (public domain, https://www.naturalearthdata.com/), simplified for web display:

- `world.json`, `europe.json`: Admin 0 countries, 1:110m (`ne_110m_admin_0_countries`), simplified further.
- `de_states.json`: Admin 1 states and provinces, 1:10m (`ne_10m_admin_1_states_provinces`), Germany's 16 states, simplified to about 0.004 degrees.

The outlines are for orientation only. They are not survey-grade borders. Natural Earth draws some disputed borders
in its own way; this project takes no position on them.
