# Radar

The radar collects open data once a day and turns it into evidence for the world model.

- `collector/radar-sammeln.php` – the collector (PHP 8, runs on plain webspace or locally:
  `php radar/collector/radar-sammeln.php --ziel radar/snapshot/wissensstand.json`). Optional keys via environment
  variables only: `DESTATIS_TOKEN` (official German statistics), `OPENALEX_KEY`, `DIP_KEY` (Bundestag documentation
  system). Without keys the corresponding sources are skipped. Set `RADAR_USER_AGENT` to your own contact.
  After collecting, it calls `python3 -m engine.tagesstand` to compute `weltlage.json`.
- `snapshot/wissensstand.json` – knowledge state: sources, news/research items (title, link, date, keywords;
  teaser texts removed), 31 time series, trends, topics.
- `snapshot/weltlage.json` – world state computed from the model and this snapshot (published by the live radar).
- `SOURCES.md` – every source and time series, generated by `list_sources.py`.
- `fetch_snapshot.sh` – fetch the latest public snapshot from the live radar.

Item lifetime: every item decays with a half-life per type (news 10 days, measurement and survey 30, parliament 45,
research 120, statistics 365); below one eighth (three half-lives) it is dropped. Time series are replaced, not
decayed. If a source fails, its last delivery stays.

Code comments are German; key terms: `quelle` source, `reihe` time series, `signal` item, `steep` topic area
(society, technology, economy, environment, politics), `halbwertszeit` half-life, `trend`, `thema` topic.
